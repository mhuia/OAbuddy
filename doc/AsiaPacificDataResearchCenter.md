# Asia-Pacific Data-Research Center (APDRC)

[https://apdrc.soest.hawaii.edu/index.php](https://apdrc.soest.hawaii.edu/index.php)

In APDRC, there are many data services that allow you to access data in different
ways, including `LAS`, `DChart`, `ERDDAP`, and `OPeNDAP`.

`LAS`, `DChart`, `ERDDAP` are web-based services, and they are mainly used for
browsing data.

`OPeNDAP` serves as a tool to access data.

## What is LAS?
[Here](https://apdrc.soest.hawaii.edu/tutorials/las8.php) is the tutorial of
`APDRC`.

[Here](https://ferret.pmel.noaa.gov/LAS/) is the information from Ferret NOAA.

### TL;DR
> `LAS` stands for **L**ive **A**ccess **S**erver. It is a highly configurable web server
> designed to provide flexible access to geo-referenced scientific data.


## What is DChart?

[Here](https://apdrc.soest.hawaii.edu/tutorials/dchart.php) is the tutorial of
`DChart`.

### TL;DR
> `DChart`: A Web interface for gridded and in-situ data


## What is ERDDAP?
[Here](https://coastwatch.pfeg.noaa.gov/erddap/information.html) is the official
document.

[Here](https://apdrc.soest.hawaii.edu/tutorials/erddap.php) is the tutorial of
`ERDDAP`.

[Here](https://www.youtube.com/watch?v=18xZoXu1USM) is a short video about
`ERDDAP`.

### TL;DR
> `ERDDAP` is a data server that gives you a simple, consistent way to download
> subsets of gridded and tabular scientific datasets in common file formats and
> make graphs and maps.


## What is OPeNDAP?

[Here](https://www.opendap.org/) is the official website of `OPeNDAP`.

[Here](https://apdrc.soest.hawaii.edu/tutorials/opendap.php) is the tutorial of
`OPeNDAP`.

At APDRC, there are three `OPeNDAP` servers used. They are GrADS Server (`GDS`),
Dapper, and THREDDS Data Server (`TDS`).

### TL;DR
> `OPeNDAP` (DODS) allows users seamless access to remote data using
> various analysis and visualization packages such as Ferret, GrADS, and MATLAB.
> The user also can use user-friendly client tools such as Panoply, IDV, and EDC
> without the user having to write scripts. OPeNDAP stands for Open-source
> Project for a Network Data Access Protocol. It is a data transport medium that
> allows access and subseting of data across the internet.
