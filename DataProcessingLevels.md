# Data Processing Levels

Most of the satellite remote sensing observations are observed in **five** main different levels ranging **from Level 0 to Level 4**.

`Level 0` products are **raw data** at full instrument resolution. At higher levels, the data are converted into more useful parameters and formats. 

The exact definitions can **vary from one type of data to another**, but generally:

| Processing Level | Note |
| ---------------- | ---- |
| `Level 0 (L0)` | Unprocessed instrument data |
| `Level 1 (L1)` | Data processed to sensor unit |
| `Level 2 (L2)` | Derived geophysical variables |
| `Level 3 (L3)` | Georeferenced data |
| `Level 4 (L4)` | Data have had the greatest amount of processing applied, possibly including modelled output and measurements from several satellites and several days. All input data are validated. |
